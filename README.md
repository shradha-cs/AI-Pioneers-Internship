# Week 1: Python for Machine Learning & Data Preprocessing

## Project Overview

This project was completed as part of the AI Pioneers Machine Learning Internship.

The project focuses on preparing a customer churn dataset for machine learning using Python.

## Tasks Performed

- Loaded and inspected the dataset using Pandas
- Checked and handled missing values
- Checked for duplicate records
- Selected relevant features
- Encoded categorical variables using one-hot encoding
- Normalized numerical features using Min-Max Scaling
- Performed basic exploratory data analysis (EDA)
- Created a final machine-learning-ready dataset

## Tools and Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- JupyterLab

## Dataset

A small synthetic customer churn dataset was used for educational purposes.

## Project Files

- `Week_1_ML_Data_Preprocessing.ipynb` — Complete Jupyter Notebook
- `Week_1_Raw_Customer_Churn_Dataset.csv` — Original dataset
- `Week_1_Cleaned_Customer_Churn_Dataset.csv` — Cleaned dataset
- `Week_1_Preprocessed_Customer_Churn_Dataset.csv` — Final preprocessed dataset
